# 供应商协同架构与接口

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 商业咨询微信 zhuatech / zhuatech2。

## 权限与数据范围

实时读取账号、角色和部门，服务端校验会话保存的密码散列是否仍有效。ALL可跨部门，DEPARTMENT限本部门，SUPPLIER限绑定供应商及受邀已发布询价。供应商角色只能包含portal权限，内部角色不能分配portal权限。页面菜单配置不代替API授权。

`rfq.write`编制/提交/封标/取消/选择；`rfq.approve`发布及定标审批；`supplier.write`维护档案；`supplier.review`准入审核；`export`下载已定标建议；`admin`管理配置；`audit`审计；`dashboard`统计；`portal`供应商报价。查看询价与供应商另需对应read权限。

## 数据库与事务

V1迁移共16张应用表（含角色权限关系表，另有Flyway历史表）：department、access_role、permission、role_permission、nav_menu、account、audit_event、system_setting、dictionary_entry、supplier、rfq、rfq_line、invitation、quote、quote_line、mutation_stamp。

supplier和rfq含乐观version。业务写入先锁部门，再锁询价/供应商，确保同部门准入更新、报价与审批串行一致；管理员修改锁基础部门保护最后管理员。报价行不可修改，重报生成新quote与quote_line，旧quote仅变更状态。

mutation_stamp唯一键(rfq_id,actor,request_key)，保存命令与输入SHA-256。相同键相同内容返回当前安全详情，不重做命令；同键不同内容409。版本号防止陈旧草稿或审批覆盖，供应商并发重报使用锁和递增报价版本，无需知道内部询价版本。

## HTTP接口

所有路径以`/api`开头，会话同源，写请求携带`/auth/csrf`返回的头名与令牌。

| 路径 | 方法与用途 |
| --- | --- |
| /auth/csrf、/auth/login、/auth/me、/auth/logout、/auth/password | 获取CSRF、登录、资料、退出和修改密码 |
| /options | GET分类与显示参数 |
| /suppliers | GET授权目录、POST新建 |
| /suppliers/{id} | PUT修改重新待审 |
| /suppliers/{id}/approve、/reject | POST准入决定与审核意见 |
| /rfqs | GET搜索/状态/分页/排序，POST草稿 |
| /rfqs/{id} | GET安全详情、PUT草稿、DELETE草稿（version查询参数） |
| /rfqs/{id}/{action} | POST状态动作及报价 |
| /rfqs/{id}/advice.json | GET冻结建议下载 |
| /dashboard、/audit | GET统计与审计 |
| /admin/{type}、/admin/{type}/{id} | GET目录，POST新建，PUT修改，DELETE未引用资源 |

询价列表参数：search、status、page（从0起）、size（1–100）、sort（newest/oldest/deadline）。动作：submit/approve/reject/close/cancel/quote/withdraw/select/award/reject-award。内部动作带version，所有询价POST动作带1–80字符requestKey。note用于审核/取消/选择理由；select带quoteId，可带exceptionReason。

## 采购建议协议

kind固定PROCUREMENT_ADVICE，schemaVersion为1.0。adviceId为询价编号，quoteId和quoteRevision明确来源；supplier为编码和名称，lines为物料编码、名称、规格、单位、数量、未税单价、税率、未税额与税额；整单包含币种、运费、总额、交期、条款、审批日期、人和选择理由。

JSON于批准定标事务中生成并持久化，不因后续主数据或参数变化重算。没有进销存连接器；接收系统须单独实现编码映射、幂等、权限、失败处理和人工订单确认。导出不附加品牌广告或二维码载荷。
