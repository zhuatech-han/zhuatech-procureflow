## 实际业务与权限

全新MySQL测试卷启动数据库、后端和前端，三者健康。V1迁移成功，16张业务表及1张迁移历史表存在。初始化管理员使用本机随机密码登录。

## 发布检查与边界

执行`python3 scripts/release-check.py`、`git diff --check`、公开文件中的实际测试凭据匹配扫描及容器日志凭据扫描。README图片、两张原始二维码哈希、公司署名、官网、微信号、非商业许可及第三方声明分别检查。

未进行商业生产部署、外部系统联调、数据库备份恢复演练、正式渗透测试或大规模负载测试。H2集成测试不替代MySQL验收；生产数据库证书、HTTPS、备份和外部身份系统需要独立配置与验证。进销存连接器尚未实现。

## 复验命令

```bash
cd backend
mvn spotless:check test package
cd ../frontend
npm ci
npm run format:check
npm run lint
npm test
npm run build
cd ..
docker compose config --quiet
docker compose -p procureflow-qa up -d --build --wait --wait-timeout 240
python3 scripts/smoke.py --allow-test-data
python3 scripts/smoke.py --allow-test-data --verify-existing 1
python3 scripts/release-check.py
git diff --check
docker compose -p procureflow-qa down -v
```

`--verify-existing`应填本次验收输出的已定标询价ID。只能清理本次独立验收环境。
