# 供应商协同操作手册

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 商业咨询微信 zhuatech / zhuatech2。

## 准备账号与准入

管理员创建采购专员、审批负责人账号，各自选择部门。采购专员填写供应商编码、名称、业务分类、联系方式、资质编号与核验说明、有效期。审批负责人核验后填写审核意见并准入，提交人不可自行审核。供应商资料再次修改会重新进入审核；有效期晚于UTC当天且启用才可受邀和定标。

管理员为供应商创建账号：选择“供应商”角色、与档案一致的部门，并绑定对应供应商。该角色只能分配门户权限。多个账号绑定同一供应商时共享该供应商的报价历史，最后一次有效重报成为当前版本。

## 编制和发布询价

采购专员建立询价标题、需求与评审要求、分类、ISO币种、截止时间、需求行和受邀名单。需求行包含编码、名称、规格、单位和数量；编码在单据中唯一。币种必须是两位小数币种，前后流程不换汇。

提交发布审批后，审批负责人可批准或退回；不能审批本人提交的询价。批准后需求和受邀名单冻结；采购专员可取消，不能提前封标。最低邀请数量为提交时系统参数，默认2，允许2–10。原有草稿参数修改后在下次提交时重新取值。

## 报价和比价

供应商在报价工作台查看受邀记录，逐行填写未税单价、税率，整单填写含税运费、交期、有效期和付款条款。有效期必须晚于询价截止；单价可为零，所有需求行必须报价。重报新增版本，旧版本不删除；截止前可撤回当前版本，再重新报价。

采购端封标前只能看供应商、状态、版本和提交时间。报价截止后，采购专员执行封标，查看含税总额、交期、有效期、条款及行报价。当前提交报价按金额排序仅供比较，不自动定标，其他版本可展开查看。已撤回、被替代、报价过期、供应商未准入/停用/资质过期的报价不能选择。

每行未税额 = 数量 × 未税单价，四舍五入两位；行税额 = 已舍入未税额 × 税率 ÷ 100，四舍五入两位。总额 = 各行未税额与税额之和 + 含税运费。

## 定标与导出

采购专员选择报价并写明价格、交期、质量或供货能力等依据。有效报价低于最低数量时必须填写例外说明，交由审批负责人复核；填写例外不是自动通过。审批负责人批准或退回，不能审批本人提交的定标建议。审批时再次检查供应商和报价有效性。

定标后结果冻结为采购建议。授权人员下载JSON，接收方核对供应商编码和物料编码后另行生成采购订单。建议编号可用作接收系统幂等键，接收系统还应比较内容摘要并保留导入记录。本版不发送订单、不签署合同、不登记库存或付款。

## 管理、日志与个人账号

系统管理维护角色、范围、账号、部门、已有权限名称、已有菜单名称/顺序/启停/权限、字典与参数。保留至少一位启用的全范围管理员；被外键引用资料不能删除。供应商按停用保留历史，询价仅草稿/退回状态可删除。

审计记录保存操作人、动作、对象、部门、时间，不写密码或完整报价载荷。询价事件通过对象编号筛选查看。个人在“账号与关于”验证原密码后修改密码，需要重新登录。
